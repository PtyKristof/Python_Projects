### Battery_&_Heating_data_BMWi3: 
The program reads battery measurement data from a BMW i3 (60 Ah) electric vehicle stored in a CSV file, generates descriptive statistics for the main battery parameters, and plots the battery current and temperature as functions of time on a shared graph.

    Data source: https://www.kaggle.com/datasets/atechnohazard/battery-and-heating-data-in-real-driving-cycles
